## Écarts avec le prompt de l'utilisateur

1. **Starter Resource Server** : le nom historique `spring-boot-starter-oauth2-resource-server` est obsolète en Boot 4. Le nom à retenir est `spring-boot-starter-security-oauth2-resource-server`. C'est pareil pour l'Authorization Server : `spring-boot-starter-security-oauth2-authorization-server`.
2. **Spring Authorization Server** n'est plus un projet séparé (`org.springframework.security:spring-security-oauth2-authorization-server` en version 1.x). Avec Boot 4.1, il est publié en **7.1.1**, aligné sur Spring Security.
3. **TypeScript « 5.x »** : la branche courante est **7.x** (7.0.2). La dernière 5.x est 5.9.3 et date de 2025-09. Tranché : **5.9.3** retenue (compatibilité de l'outillage du front avec la branche 7 non vérifiée ; voir le memlog de l'architecture).
4. **React Router** : en v8 (8.4.0), le paquet est `react-router`. `react-router-dom` n'existe plus au-delà de 7.18.4.
5. **Testcontainers « modules postgresql et kafka »** : en 2.x, les artefacts s'appellent `testcontainers-postgresql` et `testcontainers-kafka`. Les noms courts `postgresql` et `kafka` s'arrêtent à 1.21.4.
6. **Maven « 3.9.x »** : la dernière 3.9.x est 3.9.16, mais 3.10.0 est sortie (2026-09-27).
7. **Trivy** : la version installée en local (0.74.0) n'est plus la dernière, c'est 0.75.0.
8. **Image Jaeger** : `jaegertracing/jaeger` existe sur Docker Hub, mais la documentation officielle v2 référence `cr.jaegertracing.io/jaegertracing/jaeger`.
9. **otel/opentelemetry-collector-contrib** : la dernière version publiée sur Docker Hub (0.161.0) a une version de retard sur l'image core (0.162.0).
10. **Spring Boot 4.x** : la « dernière » version listée sur Maven Central est 4.2.0-M2, qui n'est qu'un jalon. La dernière GA est 4.1.1.
11. **Valeurs par défaut à surcharger** : les propriétés `management.opentelemetry.tracing.export.otlp.endpoint`, `management.tracing.sampling.probability`, `spring.kafka.template.observation-enabled` et `spring.kafka.listener.observation-enabled` existent toutes telles quelles. En revanche, leurs valeurs par défaut sont 0.1 pour l'échantillonnage et false pour les observations Kafka. Il faut donc les surcharger explicitement.
